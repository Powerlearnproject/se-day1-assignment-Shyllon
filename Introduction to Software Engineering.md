#Part 1: Introduction to Software Engineering

What is Software Engineering? The world is changing rapidly, and at the core of this changes is technology. Software developers are the agent of the change. Software engineering is the used of established engireering principles to build, deploy and maintain aapplication and system for effective management of task and other human activities.
The importance of software engineering cannot be over emphasized. Software engineering ensures scalability of exiting application to meet growing demand. Sftware engineering also helps in optimizing softwares for better performance.

Three key milestones in the development of software engineering are;
1. The 1968 NATO Conference of Software Engineering - It marked the birth of Software Engineering as a discipline.
2. The use of Object-Oriented Language - This revolutioned the way software are designed, enabling developers to create modular codes 
3. The Agile Manifesto of 2001 - Changed the traditional rigid approach to a flexible iterative approach in software development.

The phases of Software Development Life Cycle is as follows;
1. Requirement gathering - understanding and documenting what the software should do
2. Design - planning the software architecture and components
3. Implementation - writing the code for the software
4. Testing - ensuring that the software works as expected
5. Deployment - releasing the software to users
6. Maintenence - on-going update and fixing of bugs

The Waterfall and Agile methodologies
Waterfall methodology is linear and sequential while Agile methodology is iterative and incremental.
Waterfall methodology is suitable for projects with well defined documentation and required minimal adjustment or changes (government website) while Agile methodology is suitable for projects with evolving changes such as a mobile application, here users feedback drive changes.

The role and responsibilities of a Software Developer, Quality Assurance Engineerer and Project MAnager in a Software Engineering Team
Software Developers: writes and maintains the codes, develop features and fixes bugs
Quality Assurance (QA) Engineers: test the software and ensures it meet quality standard
Project Manager: oversees the project and ensures it stays on scheduled, within budget and meet the expectations of the stakeholders

Discuss the importance of Integrated Development Environments (IDEs) and Version Control Systems (VCS) in the software development process. Give examples of each.
Integrated Development Environments provides a comprehensive environment for writing, debbugging and testing code, example is Visual Studio Code and Version Control System track changes to codes and allow multiple developers work on the same project simulteanously, example is Git.

What are some common challenges faced by software engineers? Provide strategies to overcome these challenges.
Keeping up with the ever evolving world of technology and fixing errors (bugs) in code - continuous learning is the way out

Explain the different types of testing (unit, integration, system, and acceptance) and their importance in software quality assurance
Unit testing: test individual functions or components for correctness
Integration testing: ensures different components work together
System testing: test the entire system and ensures it meets requirement
Acceptance testing: it deals with validation of software meeting the desired requirement

#Part 2: Introduction to AI and Prompt Engineering

Define prompt engineering and discuss its importance in interacting with AI models.
Prompt engineering is the process of inputting queries for a desired response from AI model. This is important because, interacting with the AI will determine the quality (accurate, relevant and useful) of response it produce.

Provide an example of a vague prompt and then improve it by making it clear, specific, and concise. Explain why the improved prompt is more effective.
Vague Prompt: Tell me about houses
Improved Prompt: Explain the difference a terrace and bungalow take into consideration the environmental impact, efficiency and maintenence cost.
The improved prompt is specific because it guides the AI on focus areas (environmental impact, efficiency and maintenance cost). It also use the word compare for relevant and informative response.
